# Vegan Tools — [vegantools.org](https://vegantools.org)

**Vegan Tools** is a web application built to navigate everyday situations in a non-vegan world through intelligent, accessible tools.

### Core Modules
- **Product Ingredient Checker:** Instant analysis of consumer goods ingredients to identify hidden animal-derived additives.
- **Menu Reader & Interpreter:** OCR and multi-modal language model integration to parse restaurant menus in multiple languages.
- **Recipe Veganizer:** Natural language transformation pipeline substituting ingredients while preserving culinary balance and nutritional value.

Built with a fast, modern responsive web stack, custom domains, and automated client-state handling.
